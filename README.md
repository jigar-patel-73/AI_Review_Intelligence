# AI Customer Review Intelligence System

An AI-powered customer review analytics platform built using Streamlit and Gemini AI.

## Features

* Sentiment Analysis
* AI Business Insights
* Complaint Detection
* Business Recommendations
* Word Cloud Visualization
* PDF Report Generation

## Tech Stack

* Python
* Streamlit
* Gemini AI
* Pandas
* Matplotlib
* WordCloud
* FPDF

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app/app.py
```
